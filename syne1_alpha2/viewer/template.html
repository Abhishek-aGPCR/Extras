Variant effect on every isoform

For any variant, this predicts — separately for each isoform — the mRNA fate (nonsense-mediated decay, splicing, start/stop loss) and, for mutations inside the muscle isoform's own exons, which functional element is hit (KASH anchor, LEWD/kinesin motif, transmembrane, a spectrin repeat, or the α2-specific N-terminus) and what losing it would do. To test a mutation in the muscle isoform, pick it in the second menu and enter coordinates relative to it.

Accepted: coding c. (exonic, intronic c.123+5G>A, UTR c.-12 / c.*30), transcript n., genomic g. / chr:pos ref>alt / VCF 6-152176461-C-A, protein p. (one- or three-letter codes) and exon N:position. Substitutions, del, dup, ins and delins. Genomic input is on the + strand of the selected assembly.
